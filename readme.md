# Didactic Jesus Game — Android (full version)

RPG Maker MZ game, published on Google Play as the paid full version.

- Package name: `com.biblegamesproject.pro`

It is managed from bgp-admin. The same full game ships on the App Store from
[didactic-jesus-game-ios](https://github.com/Bible-Games-Project/didactic-jesus-game-ios),
because the two stores use different app IDs. Any change to the game content has to
be pushed to both repositories.

`bun run build` copies the game into `dist/`. There is no other build step.

The history before the move to this organization comes from `biblegamesproject/didactic-jesus-game`.
